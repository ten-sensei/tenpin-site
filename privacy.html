プライバシーポリシー

制定: 2026年10月18日

TENPIN（以下「本サービス」）が、Google スプレッドシート連携で受け取る Google のデータをどう扱うかを説明します。本サービスは、ここに書いた範囲を超えてデータを使いません。

1. Google のデータの扱い

求める許可

Google ドライブの drive.file（https://www.googleapis.com/auth/drive.file）だけを求めます。この許可で扱えるのは、本サービスが作ったファイルと、利用者が本サービスで開いたファイルだけです。ドライブのほかのファイル、メール、カレンダー、Google アカウントのプロフィールにはアクセスしません。

使い方

Google にアクセスするのは、利用者が操作したとき（画面での操作、または利用者が自分の AI アシスタントから頼んだとき）だけです。

  • 利用者のドライブにフォルダとスプレッドシートを作り、本サービスの表を書き出します。
  • 書き出す場所を決めるために、そのスプレッドシートの中身を読みます。
  • 利用者が読み込みを選んだときに、シートの値を読み込み、その利用者の記録として保存します。

保存するもの

  • 連携を続けるための鍵（暗号化して保存します）
  • 本サービスが作ったファイルの情報
  • 利用者が読み込みを選んだ値

スプレッドシートの中身は、利用者が読み込みを選んだ値のほかは保存しません。

共有

  • Google のデータを第三者に売ったり渡したりせず、広告や、汎用の AI・機械学習のモデルの学習には使いません。
  • 利用者が自分の AI アシスタントから本サービスを使うときは、利用者の指示で、そのデータがその AI のサービスに渡ります。
  • 不正の調査など安全のため、または法令に従うために必要な場合に限り、開示することがあります。
  • 運営者は、利用者の同意がある場合、不具合や不正の調査に必要な場合、法令に従う場合を除き、Google のデータを見ません。

連携の解除

本サービスの設定画面で連携を解除すると、Google 側の許可も取り消し、保存した鍵とファイルの情報を削除します。Google アカウントの設定からも、いつでも許可を取り消せます。ドライブのファイルは利用者のものなので削除しません。なお、バックアップには一定期間（最長14日）残ります。

Google API Services User Data Policy

本サービスが Google の API から受け取った情報の利用と、ほかのアプリへの移転は、Limited Use の要件を含む Google API Services User Data Policy に従います。

2. そのほかの情報

アカウントのメールアドレスなど、そのほかの情報は、本サービスを提供するためだけに使います。

3. 変更とお問い合わせ

このポリシーを変更するときは、このページでお知らせします。Google のデータをここに書いていない使い方で使うときは、先にこのページを改め、あらためて同意をいただきます。

ご利用中の方は、TENPIN に招待した運営者へ直接ご連絡ください。ご自身の情報の開示・訂正・削除などのご希望も、同じく運営者へお伝えください。

Google user data (English)

  • TENPIN requests only the drive.file scope and can access only files it created or that the user opened with it.
  • It accesses Google only when the user acts: it creates folders and spreadsheets, writes TENPIN tables, reads those spreadsheets to find where to write, and imports values only when the user chooses to.
  • It stores the authorization token (encrypted), information about the files it created, and values the user imports. Other spreadsheet contents are not stored.
  • It does not sell or transfer Google user data, and does not use it for advertising or to train generalized AI/ML models. Data reaches the user's own AI assistant only at the user's direction. Humans do not read the data except with consent, for security, or as required by law.
  • Disconnecting revokes the grant at Google and deletes the stored token and file information (backups are kept for up to 14 days). Files in the user's Drive are not deleted.
  • TENPIN's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
  • Contact: current users should contact the operator who invited them, including for requests to access, correct, or delete their data.
